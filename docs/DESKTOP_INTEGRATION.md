# Desktop integration

Target file explorers:

- GNOME Files / Nautilus via `nautilus-python` extension.
- Nemo/Caja via compatible Python extensions.
- KDE Dolphin via `.desktop` service menu.

Planned actions:

- Sync now.
- Copy Dropbox share link.
- Show sync status.
- Pause/resume sync.
- Resolve conflict using local, remote, or newest.

Status emblems need per-file-explorer adapters and are phase 2.
